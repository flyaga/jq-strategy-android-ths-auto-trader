# 聚宽策略实盘安卓手机同花顺自动交易
# 关于
现在聚宽实盘方案有不少，大多是聚宽模拟策略推送交易信号到Redis，然后本地电脑/电脑在QMT端/脚本读取redis信号。然后在QMT下单进行交易，或者在同花顺下单程序里模拟点击进行交易。

这些方案都要求电脑开盘时一直在线，QMT对资金有要求，现在好像还在限制QMT使用，而模拟点击不能开机做其他事。于是想干嘛一定要在电脑上自动交易啊，正好家里由不少闲置的安卓手机，现在手机就是个小电脑，能24小时在线，完全可以手机上直接登录聚宽账户得到模拟策略的交易信号，然后在手机同花顺模拟点击自动下单，不用电脑，不用QMT，不用中转站，技术架构简单，24小时在线，省钱节能。

有了这个想法后，AI辅助开发了这个聚宽策略手机自动化实盘脚本，只支持安卓手机，苹果手机的大家可自行开发，原理差不多。
# 使用步骤
1、安卓手机上安装同花顺，增加自己的券商账号

2、安卓手机上安装ascript安卓版本( https://www.ascript.cn/ )，使用的是无障碍模式，按要求设置好无障碍等权限。

3、然后克隆策略，复制策略代码74行之后的代码，粘贴到ascripts新建的项目中。

4、根据自己的情况修改聚宽用户名和密码，还有策略链接，手机锁屏密码（需要改成数字密码，每个手机锁屏密码的坐标不同，可能需要调试改参数），手机同花顺交易密码（ths实盘的话，需要调试修改密码坐标）。

5、由于脚本中明码保存了相关的用户名和密码信息，请自行确保设备环境安全，避免在共享设备上使用
